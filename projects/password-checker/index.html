🔐 Password Strength & Breach-Pattern Checker

Type a password to see how quickly common cracking techniques would find it. The checker looks for the patterns that attacker wordlists and mangling rules try first: common passwords, dictionary words with leetspeak, Season+Year, keyboard walks, sequences, repeats, dates and personal info.

🛡️ Private by design: everything runs locally in your browser. The page's Content-Security-Policy blocks all network connections (connect-src 'none'), and nothing is stored. It does not query real breach databases; it flags breach-style patterns. Still, prefer testing a password that is similar to yours rather than a real one.

How the estimate works

  • Each pattern gets a rough guess count (e.g. a dictionary word ≈ its rank × capitalization/leet variants).
  • Dynamic programming finds the cheapest mix of patterns + brute-forced characters covering the whole password.
  • Crack times assume an attacker searches half the space on average: offline against a fast, unsalted hash at 10 billion guesses/s, and online against a rate-limited login at 10 guesses/s.
  • Wordlists are small and illustrative, so treat results as an estimate, not a guarantee. Use a password manager and MFA.

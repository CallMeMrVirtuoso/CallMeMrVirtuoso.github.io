🧹 AD Account Hygiene Audit

A read-only PowerShell script that scans Active Directory user accounts for problems that commonly come up in security reviews: stale accounts, accounts that were never used, passwords that never expire or are not required, very old passwords, and disabled accounts that still sit in groups. Privileged (adminCount=1) accounts are flagged and escalated.

  • PowerShell
  • Active Directory
  • Identity & access
  • PSScriptAnalyzer
⬇ Download Invoke-ADHygieneAudit.ps1 ⬇ README.md ⬇ Test-WithMockData.ps1

What it checks

CheckFindsSeverity
StaleEnabled, no logon in 90+ daysMedium
NeverLoggedOnEnabled, 30+ days old, never usedMedium
PwdNeverExpires"Password never expires" setMedium
PwdNotRequiredPASSWD_NOTREQD flag setHigh
OldPasswordPassword older than 365 daysLow
DisabledInGroupsDisabled but still in groupsLow

Thresholds are parameters (-StaleDays, -NewAccountGraceDays, -PasswordAgeDays). Scope with -SearchBase / -Server.

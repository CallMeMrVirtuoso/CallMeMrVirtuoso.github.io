Small, working tools around the work I do in IT support and security: identity hygiene, log triage, passwords and networking. Everything runs in the browser or as a read-only script, and all the source is viewable.

Password Strength & Breach-Pattern Checker

Estimates how fast a password falls to real cracking techniques (wordlists, leetspeak, Season+Year, keyboard walks) and generates strong random passwords. Fully offline: the page's CSP blocks all network requests.
